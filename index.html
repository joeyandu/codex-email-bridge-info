Codex Email Bridge

A personal desktop utility that sends an email when an owner's Codex task finishes or asks for a choice.

This is an independent personal tool. It is not a Google or OpenAI product and is not offered as a public sign-up service.

How it works

The utility runs on the owner's Mac, reads local task events, and sends a notification through the Gmail API to a single configured recipient. Emails can include the task name, final response, questions, links, and a text attachment for long responses.

Google permissions

It requests permission to send email, plus basic email identity to confirm the intended sending account. It does not request permission to read, search, or delete Gmail messages.

See the privacy policy and usage terms.
